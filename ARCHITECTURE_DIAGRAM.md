# 3D Landmark Detection - Visual Architecture Flow

## Stage 1: PointTransformerLandmark

```
Input Point Cloud: (B, 3, N)
         │
         ▼
┌─────────────────────────────────────────────────────────────┐
│                PointTransformer Backbone                    │
│                     (Encoder Only)                         │
│  ┌─────────────────────────────────────────────────────┐   │
│  │ Input: (B*N, 3) → Encoder → Output: (B*N, 32)    │   │
│  └─────────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────────┘
         │
         ▼
Local Features: (B, 32, N)
         │
         ▼
┌─────────────────────────────────────────────────────────────┐
│                Global Feature Processing                    │
│  ┌─────────────────────────────────────────────────────┐   │
│  │ Max Pooling: (B, 32, N) → (B, 32, 1) → (B, 32)  │   │
│  └─────────────────────────────────────────────────────┘   │
│  ┌─────────────────────────────────────────────────────┐   │
│  │ Global MLP: 32 → 512 → 256                        │   │
│  └─────────────────────────────────────────────────────┘   │
│  ┌─────────────────────────────────────────────────────┐   │
│  │ Expand: (B, 256) → (B, 256, N)                   │   │
│  └─────────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────────┘
         │
         ▼
Feature Fusion: (B, 32, N) + (B, 256, N) = (B, 288, N)
         │
         ▼
┌─────────────────────────────────────────────────────────────┐
│                    HeatmapHead (Conv1D)                    │
│  ┌─────────────────────────────────────────────────────┐   │
│  │ Conv1D(288→512, k=1) + BN + ReLU                 │   │
│  └─────────────────────────────────────────────────────┘   │
│  ┌─────────────────────────────────────────────────────┐   │
│  │ Conv1D(512→256, k=1) + BN + ReLU                 │   │
│  └─────────────────────────────────────────────────────┘   │
│  ┌─────────────────────────────────────────────────────┐   │
│  │ Conv1D(256→68, k=1)                               │   │
│  └─────────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────────┘
         │
         ▼
Output Heatmap: (B, 68, N)
         │
         ▼
┌─────────────────────────────────────────────────────────────┐
│                Landmark Extraction                         │
│  ┌─────────────────────────────────────────────────────┐   │
│  │ ArgMax Operation: Find peak points for each        │   │
│  │ landmark → (B, 68, 3) coordinates                 │   │
│  └─────────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────────┘
```

## Stage 2: PointTransformerStage2

```
Input Point Cloud: (B, 3, N)
         │
         ▼
┌─────────────────────────────────────────────────────────────┐
│                Stage 1 Model (Inherited)                   │
│  ┌─────────────────────────────────────────────────────┐   │
│  │ Complete Stage 1 pipeline → Heatmap (B, 68, N)    │   │
│  └─────────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────────┘
         │
         ▼
Heatmap: (B, 68, N)
         │
         ▼
┌─────────────────────────────────────────────────────────────┐
│                Global Feature Extraction                    │
│  ┌─────────────────────────────────────────────────────┐   │
│  │ From heatmaps → Global features (B, 512)           │   │
│  └─────────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────────┘
         │
         ▼
┌─────────────────────────────────────────────────────────────┐
│                CoarseToFineHead (MLP)                      │
│  ┌─────────────────────────────────────────────────────┐   │
│  │ Coarse MLP: (B, 512) → (B, 68, 3)                │   │
│  └─────────────────────────────────────────────────────┘   │
│  ┌─────────────────────────────────────────────────────┐   │
│  │ Refinement MLP: (B, 512+204) → (B, 68, 3)        │   │
│  │ Input: Global features + Coarse coordinates        │   │
│  └─────────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────────┘
         │
         ▼
Output: Heatmap + Coarse + Refined Landmarks
```

## 핵심 설계 아이디어

### 1. **Multi-scale Feature Learning**
```
Point Level (Local)    Global Level (Context)
     │                       │
     ▼                       ▼
(B, 32, N) features   (B, 256) features
     │                       │
     └──────────┬───────────┘
                ▼
        (B, 288, N) combined
```

### 2. **Feature Hierarchy**
```
┌─────────────────────────────────────────────────────────────┐
│                    Feature Levels                           │
├─────────────────────────────────────────────────────────────┤
│ Level 1: Raw 3D coordinates (B, 3, N)                     │
│ Level 2: PointTransformer features (B, 32, N)             │
│ Level 3: Global context features (B, 256, N)              │
│ Level 4: Combined features (B, 288, N)                    │
│ Level 5: Landmark probabilities (B, 68, N)                │
│ Level 6: Final coordinates (B, 68, 3)                     │
└─────────────────────────────────────────────────────────────┘
```

### 3. **Why This Architecture Works**

1. **PointTransformer**: 3D 공간의 기하학적 관계 학습
2. **Global Features**: 전체 얼굴의 구조적 정보 제공
3. **Feature Fusion**: Local + Global = 더 풍부한 표현
4. **Conv1D**: 포인트별 독립적 처리로 공간적 정확도 확보
5. **Multi-stage**: Stage 1의 coarse → Stage 2의 fine refinement

이 구조는 **3D 공간의 기하학적 특성을 보존하면서 전역적 맥락을 활용**하여 정확한 랜드마크 검출을 가능하게 합니다.
